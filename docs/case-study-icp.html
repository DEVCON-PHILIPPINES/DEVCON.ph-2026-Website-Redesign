DevRel case study · ICP Philippines

The biggest smart contracts code camp series in the Philippines

With ISLA CAMP (ICP HUB Philippines), DEVCON runs a nationwide smart contracts builder education advocacy and code camps, taking blockchain training to schools and cities that rarely get it.

Series results

Reach, then real deployments

  • 200,000+Online reach of ICP-supported events and content
  • 3,000+Students and developers reached offline
  • 700+Developers engaged in hands-on code camps
  • 500+Smart contract projects completed and deployed
  • 60+ schools and partners
  • 56% average deployment completion
  • 80+ trained mentors nationwide
  • 30+ training sessions and code camps
  • 10+ underserved and new tech communities
  • 2 major summits
Where it happened

Top code camp locations by projects deployed

  • Lucena81 projects
  • Iloilo61
  • Laguna55
  • Mindoro42
  • Davao34
  • Lipa25
  • CDO22
The approach

Go where the opportunities aren’t

The series focuses on underserved and new tech communities, so students can publish their first smart contract as part of their portfolio.

  • Mindoro
  • Lucena
  • Leyte
  • Baguio
  • Tagum
  • Bukidnon
  • General Santos

Two major summits anchored the series: the Mindanao Summit in Davao and the CALABARZON Summit in Lipa.

The partner’s goal

From technology consumers to active builders

For ISLA CAMP founder Nelson Lumbres, the partnership gives Filipino developers a way to stand out globally and reach transformative opportunities.

The bigger outcome

Code camps that grow chapters

The camps helped DEVCON build and support new chapters in Laguna, Bukidnon, and Pampanga.

“Empowering the builder community to be future-ready and decentralizing access to tech opportunities.”

Dom De Leon, Executive Director, DEVCON Philippines

This partnership covers emerging-technology education and code camps only. It is not financial advice on cryptocurrency.
